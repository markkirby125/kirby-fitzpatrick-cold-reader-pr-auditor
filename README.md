## Core Patterns

- **Cold Reader Auditor**: Cold Reader Protocol: audit PRs and docs assuming zero prior context; forbid ungrounded tribal knowledge.
- **Practical Application**: PR summaries ensuring claims link causally to benchmark evidence.
- **Verification Gate**: Enforces clean syntax, zero filler, and deterministic causality.
